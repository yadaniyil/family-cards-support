# Family Cards — support site

Support and privacy pages for the iOS app **Family Cards: Guess & Reveal**.

Published with GitHub Pages:

- Support: https://yadaniyil.github.io/family-cards-support/
- Privacy: https://yadaniyil.github.io/family-cards-support/privacy.html

Both URLs are referenced from the app's App Store Connect listing. Changing the
file names will break the App Store listing.
